# Shared Terra ↔ Sol Workflow

Read first: `PROJECT.md`, `NOW.md`, `TASKS.md`, `LOG.md`, `LIVE-STATE.md`, `docs/SOL_UAT.md`. Sync GitHub before all repo work. Do not overwrite uncommitted or divergent changes; do not force push.

**Terra** (this chat): product direction, architecture, acceptance criteria, cross-agent reviews, and bounded changes. **Sol** (Codex): implementation, local execution, tests, browser UAT, debugging, screenshots, commits and verified handoff. One context writer at a time; commit before switching agents. Never claim code is live without verifying a deployment. Do not store secrets.

End every implementation with: task / status / changed / decisions / verification / live state / known issues / next action / commit SHA.
