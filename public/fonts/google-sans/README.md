# Google Sans body font

Official Google Fonts Latin variable WOFF2, normal style, weights 400–700.
Downloaded 2026-10-21; unmodified and locally hosted with `font-display: swap`.
The complete SIL Open Font License is included in `OFL.txt`.

Upstream project and license: https://github.com/googlefonts/googlesans
