# Great Lakes Hackathon Challenge · opening study

Silent 15-second, 1920×1080, 30FPS Remotion composition. Audio and the full competition explainer come later. All animated artwork is editable SVG/HTML; no external footage is required.

```powershell
cd promo
npm ci
npm run studio
npm run render
```

The render command writes `out/glhc-opening.mp4`. Remotion Studio provides playback and a frame scrubber. Edit scene timing and copy in `src/index.jsx`.

## Timing

- 0–4.17s: expanding pulse, geographic lakes, “What if you could hear the lakes?”
- 4.17–7.9s: “Turn data into feeling” and abstract waveform.
- 7.9–11.6s: light/sound/movement and a conceptual kinetic light installation.
- 11.6–15s: official event title and “No experience needed.”

Navy #052638, yellow #ffd450, aqua #89d3d0 and white #f6f6ed connect to the website. Illustrations and waveform are conceptual, not sensor readings or prior participant projects. This opening does not yet include dates, prizes, organizer logos or the display commitment. Full promo must state that top winners will have their designs displayed at tourist attractions.
